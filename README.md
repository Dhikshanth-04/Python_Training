Tuples in python;
- They are immutable, ordered and can hold different data types
- Single element can be deleted using del

Decorator in python : 
- A decorator is the function that takes another function as the input and returns the enhanced edition of the function without altering the original function.

Generators in python :
- Generators are special function and memory efficient in python, where only one value is generated at a time, instead of producing the whole results, this method is known as lazy evaluation.

Machine learning : 
- Machine learning is the technique, where the computer learns from the data and make decision instead of explicit programming.
- It works by identifying patterns in data and use them for predictions.
- ML is subset of AI, where the systems learns patterns from the historical data and make predictions or decision without being explicitly programming.

Supervised Learning in ML:
- It uses labeld data where both input and expected output are available. The model learns the relationship and predicts the output for new data.
